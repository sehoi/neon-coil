# NEON TRIAD

브라우저에서 바로 돌아가는 **3매치 타일 게임**(셰프양 · 양타양 계열). 같은 무늬 3장을 모아 판을 비운다.
[NEON COIL](../) 과 같은 규칙으로 만들었다 — 빌드 도구도, 외부 라이브러리도, 에셋 파일도 없다.
타일과 무늬는 전부 Canvas 벡터, 사운드는 WebAudio 절차 생성이다.

### ▶ [지금 플레이하기](https://sehoi.github.io/neon-coil/triad/)

## 로컬에서 실행

저장소 루트에서:

```bash
node serve.mjs
```

그 다음 http://localhost:5173/triad/ 를 연다.
(ES 모듈은 `file://` 에서 CORS 로 막히므로 `index.html` 을 더블클릭하면 동작하지 않는다)

## 규칙

- **덮이지 않은 타일만 집을 수 있다.** 위에 한 장이라도 걸쳐 있으면 흐리게 보이고, 눌러도 흔들리기만 한다.
- 집은 타일은 아래 **트레이 7칸**에 쌓인다. 같은 무늬는 항상 붙어서 놓인다.
- 같은 무늬 **3장**이 모이면 사라지고 점수가 된다.
- 판을 다 비우면 다음 레벨. **트레이 7칸이 다 차면 그 판은 끝난다.**
- 매치를 5수 안에 이어 가면 **콤보**가 붙는다 (매치 60점 + 콤보당 20점, 최대 6단).
- 클리어 보너스 300점 + 파 타임보다 빠른 만큼 속도 보너스 최대 400점.

### 도구

레벨마다 다시 채워진다.

| 도구 | 키 | 효과 |
|---|---|---|
| **되돌리기** | `Z` | 마지막에 집은 한 장을 원래 자리로 돌린다 (레벨당 3회) |
| **빼내기** | `X` | 트레이에서 3장을 판 맨 위로 되돌린다 (레벨당 1회) |
| **섞기** | `C` | 판에 남은 타일의 무늬를 다시 푼다 (레벨 2부터, 레벨당 1회) |

트레이가 차서 진 뒤에도 **빼내기가 남아 있으면 그 자리에서 이어할 수 있다.**

## 조작

| 입력 | 동작 |
|---|---|
| 클릭 / 탭 | 타일 집기 · 버튼 |
| `Z` `X` `C` | 되돌리기 · 빼내기 · 섞기 |
| `Esc` / `P` | 일시정지 |
| `M` / `G` | 음소거 / 글로우 전환 |

세로 화면 720×1280 논리 해상도를 레터박스로 맞춘다. 모바일은 세로로 잡고 하면 된다.

## 반드시 풀리는 판

무작위로 무늬를 뿌리면 **손도 못 대는 판**이 나온다. 그래서 순서를 거꾸로 잡는다.

1. 먼저 타일 위치와 층만 만든다 (`game/layout.js`).
2. 매 단계에서 **덮이지 않은 타일만** 골라 하나씩 빼는 무작위 순서를 만든다 (`solveOrder`).
3. 그 순서를 앞에서부터 **3장씩 묶어 같은 무늬**를 준다 (`dealSymbols`).

그 순서대로만 집으면 트레이에 3장 넘게 쌓이지 않고 판이 비워진다 — 즉 해답이 반드시 하나는 있다.
순서 자체는 무작위라 플레이어에게는 흩어져 보인다.

**섞기도 같은 방식으로 다시 푼다**(`redeal`). 트레이에 이미 들어간 낱장을 무시하면 섞은 뒤에 못 푸는 판이 되므로,
미완성 짝을 채울 무늬를 새 순서의 맨 앞에 놓는다. 많이 모인 짝부터 채워야 트레이가 먼저 비워진다.

검증은 브라우저 없이 돌린다:

```bash
node triad/tools/simulate.mjs 16 60     # 레벨 수, 판 수
```

정답 순서대로 두면 전부 클리어되는지, 섞기 뒤에도 그대로인지 확인하고,
사람 흉내를 낸 그리디 전략의 클리어율로 난이도 곡선을 뽑는다.

| 레벨 | 타일 | 층 | 무늬 | 그리디 클리어율 |
|---|---|---|---|---|
| 1 | 30 | 3 | 4 | 97% |
| 4 | 48 | 4 | 5 | 73% |
| 8 | 72 | 6 | 6 | 47% |
| 12 | 96 | 6 | 8 | 33% |
| 16 | 120 | 6 | 9 | 15% |

그리디는 앞을 못 보고 도구도 안 쓴다. 사람은 아래층 무늬까지 보고 두므로 이보다 잘한다.

## 구조

```
index.html · style.css
src/
  main.js        루프 + 상태 머신 (title · play · pause · clear · over)
  config.js      논리 해상도 · 화면 영역 · DPR
  core/          rng · audio · save · input          [NEON COIL 이식]
  data/          tuning(모든 밸런싱 수치) · symbols(무늬 12종 벡터)
  game/          layout(배치) · deal(무늬 배분) · board(덮임 판정) · session(진행·도구·점수)
  render/        geom(좌표 변환) · tiles · renderer · particles
  ui/            hud · screens · widgets · icons · rects
tools/
  simulate.mjs   판 생성기 검증 (node)
```

밸런싱은 [src/data/tuning.js](src/data/tuning.js) 한 파일에 모여 있다.
게임 로직(`game/`)은 DOM 도 Canvas 도 모르기 때문에 node 에서 그대로 돌려 검증할 수 있다.

## 디버그 훅

```js
TR.start(7)     // 레벨 7 로 시작
TR.solve(0.05)  // 생성 시점의 정답 순서대로 자동으로 푼다
TR.free()       // 지금 집을 수 있는 타일들
TR.pick(tile)   // 한 장 집기
TR.session      // 판 상태 전체
```

## 현재 상태

규칙·레벨 진행·도구·점수·기록까지 한 바퀴 돈다. 브라우저에서 확인한 것:
덮인 타일 클릭 거부, 트레이 매치와 콤보, 트레이 만석 패배와 빼내기 이어하기,
되돌리기·섞기, 일시정지, 레벨 이월 점수, 로컬 기록 저장과 재방문 유지, 모바일 터치.

남은 것:
- **사람 손으로 하는 밸런싱** — 난이도 곡선은 시뮬레이션으로만 확인했다
- 레벨 30 이후의 판 모양 (지금은 6층 120장에서 멈춘다)
- 업적과 일일 판 (같은 시드를 하루 동안 공유)
